# 租房合同审查测试说明与标准答案

本包只含虚构人物与地址，用于检验“签前有数”的文件导入、风险识别、证据回查、建议和复查流程。合同正文中的条款是测试输入，不代表推荐签署的合同。请一次只导入一份合同；标准答案不要上传给审查功能。

## 预期风险点

以下为测试判分用的“应提示审查或协商”项目，不等同于每句话当然无效。评价时要求产品说明风险条件，不要将所有争议条款一律断言违法。

| 编号 | 文件 | 应命中的原文证据 | 期待解释和行动 |
| --- | --- | --- | --- |
| B1 | 02、04 | “甲方可随时单方调整月租金；乙方不接受调整的，应在7日内搬离，押金不予退还。” | 指出租期内单方调价、搬离与押金联动风险；建议租期内固定租金，变更须双方书面同意 |
| B2 | 02、04 | “甲方可直接扣除全屋保洁费800元、家具自然折旧费600元及甲方认为必要的其他费用，无需提供票据。剩余押金在退租后60个工作日内退还。” | 指出固定扣费、无凭证、开放式扣款和过长/不利的返还周期；要求列明扣减情形、凭证、返还时间 |
| B3 | 02、04 | “甲方可立即换锁并收回房屋，已交租金和押金均不退还；乙方另付六个月租金作为违约金。” | 指出自行换锁、押金/租金全不退、叠加高额违约责任；建议催告、合理期限和依法处理 |
| B4 | 02、04 | “甲方可随时持备用钥匙入户检查或带看，无须事先通知乙方。” | 指出隐私和居住安宁风险；建议事先通知并协商，紧急情况另列 |
| B5 | 02、04 | “家具电器发生任何故障，均由乙方自费维修；甲方不承担维修责任。” | 指出未区分损坏原因的维修转嫁；建议区分自然故障与乙方使用不当 |
| B6 | 02、04 | “甲方提前解约无须赔偿；乙方提前解约须另付三个月租金作为违约金。” | 指出解除责任不对称；建议明确双方通知、交接及相称的违约责任 |
| B7 | 02、04 | “未尽事宜由甲方最终解释。” | 指出单方解释权/格式条款风险；建议争议时双方协商并依法处理 |
| C1 | 03 | 表格“押金返还……7个工作日内退还余额”与附件“押金统一在退租后30个工作日内返还” | 必须发现同一合同内部冲突；不要擅自替双方认定哪条当然优先 |
| C2 | 03 | “每次退租固定扣除全屋清洁费500元，无需提交清洁票据。” | 指出固定扣费和无凭证；建议按实际、合理费用核对 |
| C3 | 03 | “墙面恢复为全新状态；是否符合要求以甲方判断为准。” | 指出可能将正常损耗转嫁、验收标准单方确定；建议以交接清单与实际损坏为准 |
| C4 | 03 | “空调故障由乙方承担维修费用，不区分故障原因。” | 指出维修责任未区分原因 |
| D1 | 06 | “每逾期一日按月租金5%付违约金。” | 指出日违约金可能过高；建议合理比例或上限，保留协商/依法调整的表述 |
| D2 | 06 | “乙方逾期超过3日，甲方有权换锁收房，押金不退。” | 指出换锁与押金当然不退的风险 |

低风险对照项：01 的“租期内租金不变”“仅可凭账单或维修票据扣除”“正常使用损耗不扣除”“提前24小时与乙方协商时间”，以及 06 的“甲方入户检查须提前24小时通知并与乙方协商”，不应被误判成对应的高风险条款。03 的主合同维修条款也不应掩盖附件的例外。

## 操作方法

1. 打开“审查合同”，依次导入 01、02、03、04、06；每次导入后先看编辑区正文，再点“开始审查”。导入 06 时用 05 核对 OCR 结果，尤其是 2,800、5%、3 日和两个日期。
2. 对 02 和 04，把风险标题、等级、原文引用、建议逐项并排比较。两个文件的实质内容相同，结果应基本一致；PDF 页眉或换行不应改变判断。
3. 点击每条风险的证据，核对高亮是否在本次导入的正文中逐字存在。随机抽 3 条阅读法条来源与建议，检查其是否真的对应这条风险。
4. 在 03 中确认主合同表格与附件都已导入，审查是否解释了两处押金返还时间冲突。若只检出其中一处，先记为“导入/结构识别失败”，不要算作模型判断正确。
5. 对 02 中至少一条风险采纳修改、写回正文并再次审查，确认原风险消失且新文本没有引入别的问题。若进入谈判台，核对话术是否针对所选原文。

## 法律核对依据

- [《住房租赁条例》第九、十、十二条（国家行政法规库）](https://xzfg.moj.gov.cn/front/law/detail?LawID=1774)：入户、押金约定与扣减、解除与腾退的基本要求。
- [《中华人民共和国民法典》租赁合同章（最高人民法院）](https://www.court.gov.cn/zixun/xiangqing/233181.html)：租赁合同内容、交付、维修、欠租催告等一般规则。
- [城镇房屋租赁合同示范文本 2025 版（国家市场监督管理总局）](https://htsfwb.samr.gov.cn/View?id=2340996b-882d-47a4-b74d-c30784628737)：用于对照押金、费用、维修和违约责任的常见约定结构。

判分时应结合合同全文与适用法律核对。对违约金金额、格式条款效力等存在事实依赖的项目，产品宜提示风险和协商方向，不宜仅凭一句话给出确定裁判结论。
