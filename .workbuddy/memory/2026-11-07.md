## 项目事实补充（供后续会话直接用）

- 合同类型枚举：`auto | lease | service | purchase | employment | cooperation`，`detectContractType` 用信号词打分，≥2 分才判定，否则回落 lease。
- 决策判定优先级（`resolveDecision`）：未填完 → 预算冲突暂停 → 有高危则先确认 → 信息缺失补全 → 可继续沟通。
- 本地存储 6 个键：`signahead-history / -ai-config / -ai-feedback / -local-only-mode / -account-id / -negotiation-session`。
- 服务端无数据库；额度与幂等走 Upstash Redis REST 或进程内 Map。
- RAG 是本地 n-gram + 关键词打分（`server/rag-engine.mjs` 124 行），非向量库。
