## 启动签前有数网站 + 修复浏览器无法访问
- 前端 Vite (qianqianyoushu/) + AI 后端 server/ai-proxy.mjs (端口 8787)
- 问题：Vite 默认只绑定 IPv6 ::1，浏览器 localhost 解析为 IPv4 127.0.0.1 导致 ERR_CONNECTION_REFUSED
- 解决：`npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`，访问 http://127.0.0.1:5174/
- 8787 端口常驻一个 AI proxy 实例（先前会话启动），新启 dev:api 会 EADDRINUSE，属正常，前端 /api 代理可用
