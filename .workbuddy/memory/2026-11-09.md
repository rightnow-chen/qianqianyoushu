## 结果页左栏换成真原件（承接 11-08 的「待用户决定」）

用户 11-08 晚问「为什么左边还是原来的样子，不是合同原文」，等于当场替我在两条备选里选了「换原件」。本轮做完并全量回归。

**结构**：`ContractPane.jsx` 从「自己排纸」改成三行分派器——`hasOriginal = file && kind !== 'text'`，有原件走新建的 `OriginalDoc.jsx`，否则走新建的 `PaperDoc.jsx`（把原 `ContractPane` 的实现整段搬过去，一行逻辑没改，只改了文件名与 props 里的 `onPickRisk`）。

**高亮方案换了**：旧实现能精确标号是因为纸是自己排的 span。真原件的 DOM 不能插节点（PDF 文本层每个 span 都是绝对定位，docx 表格会塌），所以用 **Custom Highlight API**（Chrome 105+ / Safari 17.2+ / Firefox 140+）。新文件 `features/docHighlight.js`：
- `indexText` 用 TreeWalker 把可见文字压成「无空白字符串 + 每字符落在 (节点, 偏移)」，`spots` 用扁平数组避免几千个对象。
- `rangeForText` 从整句开始试，找不到依次缩到 40 / 24 / 16 字——跨页、跨单元格切断的句子靠前缀兜。
- `scrollRangeIntoCenter` 用 Range 的 rect 算，highlight 不支持也能滚。

**反向交互**：点原件上标色的句子 → 右侧跳到对应风险。高亮没有 DOM 节点可挂 onClick，所以用 `caretRangeFromPoint`（Safari 走 `caretPositionFromPoint`）+ `range.isPointInRange`。用户正在框选文字时不触发，否则想复制一句就被弹走。

**PDF 改两步画**：`filePreview.js` 的 `renderWithText` 拆成 `preparePage`（建空格 canvas + 渲染 TextLayer，返回 `{hasText, draw}`）+ `draw()`。22 页合同先出全部文字层再逐页补画面，不用干等五六秒。e2e 抓到过「断言时文字层还没挂上」的假失败，脚本里改成 `waitForSelector('.orig-page .textLayer span')`。

**Word/图片**：Word 走 `renderDocx` + `fitDocxToWidth`，图片走 objectURL 原图（`useMemo` 建、卸载 revoke）。

**写进代码的取舍**：图片和扫描件 PDF 没有文字层 → 高亮失效，但 `warn-strip` / `orig-note` 明确告诉用户「右边每条风险都附了原句，可以对着页码自己找」，不装作能定位。

## 拍照上传：结果页不摆照片，只给排好版的文字

用户要求：「图片的话不用展示原件，直接是排完版的文字即可」。承接上一条我提到的「图片/扫描件没法句子级高亮」——他的选择是干脆不显示照片。

- `ContractPane` 的 `hasOriginal` 从 `kind !== 'text'` 收紧成 `kind === 'pdf' || kind === 'word'`，图片落回 `PaperDoc`。
- `OriginalDoc` 里的图片分支整段删掉（`createImageUrl` / objectURL 释放 / `<img>` / `.orig-image` 样式 / `SOURCE_LABEL.image` / `FAIL_COPY.image`），现在只剩 pdf/word 两条路，`status` 的 `'image'` 值也去掉了。
- `PaperDoc` 收 `kind`：图片时标题写「识别文字」+ 右侧「按条款重排」，其他写「合同原文」+「纯文本」。理由：OCR 出来的字不能叫「原文」，否则用户以为照片原样在下面。顺带补了 `pages.length === 0` 的空状态（原来会渲染出一个没内容的纸框）。
- **确认页不动**：那里照片 + 「照片 / 识别文字」两档保留，因为那一刻的任务是核对 OCR 准不准，必须两栏对照。两页规则不同，写进 README 的对照表了。

**验证手段**：dist 是纯静态的，`/api/ocr/image` 打不通，所以 e2e 的静态服务器和 `scripts/verify/upload-shot.mjs` 都加了一条 POST 拦截，回一份固定文本（用真实合同样本当「识别结果」）。这样图片路径能在没有后端的情况下走完四条屏。新增 e2e 第 20 步：结果页必须是 `.paper .page` ≥ 1、`.docpane img` 为 0、`.docpane.orig` 为 0、标题为「识别文字」。

门槛：lint 零告警 / build 7.52s / 13 组单测 / **e2e 20 步** / verify:mvp 12/12。
