## 0 一句话结论

PRD v1.2 与原型 V3 是同一套东西（5 屏 + 5 Tab 的签约前审查闭环），而 `app/` 里跑的是上一代产品（侧栏 4 模块 + 预算通勤决策 + 自由 AI 对话）。

**这不是"改几处文案"，是一次 IA 重装**：留引擎、换外壳。核心工作量不在写代码，在于**把现有"高/中/低风险 + 无金额"的审查模型，改造成 PRD 要求的"必须改/建议确认/仅提醒 + 金额可算"的九件套模型**。

三条判断先说：

1. **原型 V3 直接作为 UI 唯一事实源**，不合并旧界面、不做折中版。旧界面的价值只剩引擎与测试。
2. **不要重写引擎**。合同解析、OCR、规则库、RAG、法条映射、docx/PDF 导出、脱敏，全部保留复用。真正要新写的是外壳与数据模型。
3. **工程量的大头是删，不是加**。`src/` 共 11,952 行 JS，其中 3,724 行（31%，实测 `wc -l`）属于 V0.1 范围外的模块（预算、通勤、房源比对、使用总览、自由 AI 对话、补贴、侧栏）；`App.css` 9,446 行里新外壳只需约 1,200 行。新外壳整体大约 3,500–4,500 行即可。

## 5 目标数据模型

V0.1 的所有界面都由这一个对象驱动，先定它，再写界面。

```js
// src/data/riskModel.js
{
  id: 'r1',
  level: 'must' | 'check' | 'note',        // 必须改 / 建议确认 / 仅提醒
  cat: '押金',                              // 9 类之一
  title: '押金：退租时扣除「全屋保洁费」',
  loc: { article: 4, sentence: 2, page: 2 },
  conf: '确定' | '需确认' | 'AI 推断',
  amount: { kind: 'loss' | 'gain' | 'none', value: 5400, unit: '总额' | '每月' | '每年' },
  consequence: '...',                       // 一句后果，能定价写金额，不能定价写机制
  original: '退租时需扣除全屋保洁费，标准由甲方核定。',
  suggestion: '...',
  why: '...',                               // 一句「为什么改」
  law: { name: '《民法典》第七百一十条', version: '2021 施行', scope: '全国性法律', url: '...' },
  scripts: { polite: '...', firm: '...' },
  objections: [{ q: '我们这一片都这样', a: '...' }, ...]
}
```

### 5.1 金额引擎（替换 15 处硬编码）
