设计说明五个决定这份原型的判断

1. 左证据，右动作

左侧永远是合同原文，右侧永远是「你该做什么」。任何风险卡被选中，左侧自动滚到那一句；点左侧任意句子，右侧弹出预设追问。结论不能脱离原文存在，这是产品的可解释性底线。

2. 三级计数替代 0–100 分

5 家竞品里 3 家用总分，但都被自身批注质疑「分数高不代表没问题」。这里只给「必须改 3 / 建议确认 2 / 仅提醒 4」，因为用户要的是「先改哪几条」。

3. 改动做到句子级 diff

竞品多数只给整段替换或条款标题级定位。这里删红增绿是字符级算出来的 LCS 差异，每条附一句「为什么改」，让用户能判断 AI 说得对不对。

4. 话术绑定条款与金额

输出不是「建议协商」，而是可以直接复制的一段话：绑定第几条、多少钱、两档语气、以及房东拒绝时的三种接法。

5. 明确不做什么

不做总分、不做账号、不做身份核验、不做强制勾选、不做「建议签 / 不建议签」。是否签约由用户决定。
