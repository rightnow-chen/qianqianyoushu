# Overseas Rental Contract Test File

This package contains a fictional, state-neutral U.S.-style residential lease in English. It is designed for testing overseas contract review products, including clause extraction, obligation mapping, evidence binding, notice analysis, deposit handling, maintenance responsibility, and cross-reference checks.

It intentionally avoids claiming to be a valid lease for a specific U.S. state. State law can change the rules on deposits, late fees, notice, entry, habitability, eviction, pets, and disclosures. Treat product outputs as test results, not legal advice.
